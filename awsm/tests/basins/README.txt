# Test suite data with two basins

## Domains
### Lakes
Lakes domain using HRRR data
Tests using Lidar data as presented in Hedrick et al. (2018)

### RME
Reynolds Mountain East domain using station data

## Reference files
The reference ("gold") files are used as the "truth" for the test suite.
Differences to output and gold files can be inspected using the Gold-NetCDF-Compare
notebook in `awsm/tests/basins`.
